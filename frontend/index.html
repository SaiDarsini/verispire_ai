FAQ

Frequently asked questions

Do I need to know how to code to use VeriSpire AI?

No. Ask in plain language. When a numeric or algorithmic check is possible, the engine writes and sandboxes Python for you and shows PASS/FAIL in the audit trail.

Which models power the agents?

Planner, generator, and independent verifier run on Gemini 2.5 Flash via google-genai. Code checks run in a local 5-second subprocess sandbox — not in the model.

Can I cancel anytime?

Yes — every plan is month-to-month with no long-term contract. Cancel from your Billing settings in one click.

Is my data secure?

All data is encrypted in transit and at rest. Sandboxed snippets run isolated with a hard timeout, captured stdout/stderr, and no lingering workdirs.
